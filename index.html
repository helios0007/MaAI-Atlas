Guide

How the MaAI Atlas works

The Atlas is a map of MaAI student research. It puts each project in a place by its meaning. Then it shows the research branches and the gaps between them.

The projects in this version are synthetic. The pipeline and all views are real. They will work without changes when real projects are added.

How it works

  1. CollectThe pipeline reads project posts from the IAAC blog. It keeps the text, the people, the references and the links.
  2. TagIt finds the methods, data, tools and domains in the text. Each tag keeps the sentence that it came from.
  3. Clean the referencesIt joins the same paper when students write it in different styles.
  4. Check the codeIt reads each GitHub repository. It gives a score from 0 to 6 for reproducibility.
  5. Measure the meaningIt changes each text into a list of numbers. Similar texts get similar numbers.
  6. Make the map and the branchesIt puts the projects on a flat map. Then it finds groups of near projects. Each group is a branch.
  7. Find the gapsIt looks for empty areas, untried pairs, outside topics and branches that become smaller.
  8. Build the basilicaEach branch builds one part. Projects are stones. Gaps are scaffold that is not built yet.
