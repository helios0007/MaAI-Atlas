Map style mockups: the 2D semantic map

Five styles drawn from the same Atlas data (192 synthetic projects). Use the mouse wheel to zoom and drag to pan in each panel. Style D changes its labels with the zoom level. Style E draws the output of the new structure stage (corridors, voids and cohorts), found with methods from cosmology.

E uses meta.structure from pipeline stage 08b (pipeline/structure.py). The trail layer is visual only; the corridors, voids and node roles come from the analysis. Mockups only. The style you choose will be built into the Atlas as a map style, with the toggle in the view bar.
